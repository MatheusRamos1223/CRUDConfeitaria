## AppDbContext.cs

Dentro do bloco existente `modelBuilder.Entity<Usuario>(usuario => { ... })`, depois do `HasIndex(u => u.Email)`:

```csharp
            // Papel salvo como TEXTO ('Admin'/'Operador'), não como número:
            // legível no Supabase e imune a reordenação do enum.
            usuario.Property(u => u.Papel)
                .HasConversion<string>()
                .HasMaxLength(Usuario.PapelTamanhoMaximo)
                // DEFAULT no banco: usuários que já existiam viram Operador na migration.
                .HasDefaultValue(Papel.Operador);

            // CHECK: o banco recusa qualquer valor fora do enum, mesmo vindo de SQL manual.
            usuario.ToTable(tabela => tabela.HasCheckConstraint(
                "CK_Usuarios_Papel",
                "\"Papel\" IN ('Admin','Operador')"));
```

`using MyCRUD.Login;` já existe. Observação: `Operador = 0` é também o padrão do C#; com `HasDefaultValue`
o EF omite a coluna no INSERT quando o valor é Operador e o banco aplica o DEFAULT — resultado idêntico.

A FK `Produto.Categoria` (RESTRICT) **não** está aqui: vem no trecho do A2. Atenção: sem o trecho do A2,
a convenção do EF criaria a FK com **CASCADE** (FK obrigatória) — não gerar M2 sem ele.

## Migration

**M1 `AdicionarPapelUsuario`** (comando, se rodar local: `dotnet ef migrations add AdicionarPapelUsuario --project MyCRUD`).
Sem SQL manual. `Up()` esperado:

```csharp
migrationBuilder.AddColumn<string>(
    name: "Papel",
    table: "Usuarios",
    type: "character varying(20)",
    maxLength: 20,
    nullable: false,
    defaultValue: "Operador");

migrationBuilder.AddCheckConstraint(
    name: "CK_Usuarios_Papel",
    table: "Usuarios",
    sql: "\"Papel\" IN ('Admin','Operador')");
```

`Down()`:

```csharp
migrationBuilder.DropCheckConstraint(name: "CK_Usuarios_Papel", table: "Usuarios");
migrationBuilder.DropColumn(name: "Papel", table: "Usuarios");
```

Snapshot (`MyCRUD.Login.Usuario`), entre `Nome` e `SenhaHash` (ordem alfabética), e o `ToTable` final:

```csharp
                    b.Property<string>("Papel")
                        .IsRequired()
                        .ValueGeneratedOnAdd()
                        .HasMaxLength(20)
                        .HasColumnType("character varying(20)")
                        .HasDefaultValue("Operador");
...
                    b.ToTable("Usuarios", t =>
                        {
                            t.HasCheckConstraint("CK_Usuarios_Papel", "\"Papel\" IN ('Admin','Operador')");
                        });
```

Antes de aplicar no Supabase: `SELECT count(*) FROM "Usuarios";` (todos virarão Operador).

## Verificação manual

Pré: M1 e M2 aplicadas, `Admin:Email` configurado, dois usuários (Admin e outro).

1. Iniciar a API sem `Admin:Email` → log `Warning` "Nenhum Admin configurado (Admin:Email)." (R36).
2. Scalar `POST /login` com o e-mail do Admin → 200 com `"papel": "Admin"`; `GET /login/eu` → `"papel": "Admin"`;
   no banco `"Papel" = 'Admin'`; log `Information` "Usuário N promovido a Admin" (R34, R35).
3. Login com outro usuário → `"papel": "Operador"`; cabeçalho mostra OPERADOR; botões Desativar/Reativar somem.
4. Operador: `DELETE /produtos/1` e `POST /produtos/1/reativar` → **403**; tela mostra "Você não tem permissão..." (R2, R14).
5. `/cadastro.html` (Development) → resposta 201 com `"papel": "Operador"` (R37).
6. `GET /produtos` → envelope `{ itens, pagina, tamanhoPagina, total, totalPaginas }`, só ativos, ordem Id (R16).
   `?tamanho=101` e `?pagina=0` → 400; `?pagina=999` → 200 `itens: []` com `total` real (R4);
   `?situacao=7` ou `?situacao=xyz` → 400.
7. `?nome=%25` (busca "%") não devolve tudo; `?nome=BOLO` acha "bolo" (R5).
8. `POST /produtos` com `categoriaId: 9999` → 400 `errors.CategoriaId = ["Categoria não encontrada."]` (R12).
   Resposta 201 traz `categoriaNome`.
9. `PUT /produtos/{id}` sem `ativo` → 200; `ativo` não muda mesmo se enviado no JSON (R13).
10. Admin: `DELETE /produtos/{id}` → 204; de novo → 204; aparece em `?situacao=Inativos`; `POST .../reativar` → 204 duas vezes (R14, R15).
    `DELETE /produtos/99999` → 404.
11. Tela Produtos: filtro Nome/Categoria/Situação, Limpar volta para Ativos, paginador, editar destaca a linha,
    desativar o último item da última página volta uma página.
12. Login no navegador → abre `/pedidos.html` (D11).
